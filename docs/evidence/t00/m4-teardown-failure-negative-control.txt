# Contract implemented in scripts/tow/test-env.js (`down()` + runWithEnvironment):
#   - no earlier workload/startup error -> runWithEnvironment rejects with the
#     teardown error (TeardownError, isTeardownFailure=true);
#   - earlier error present -> that error stays the rejection and carries the
#     teardown failure as error.teardownError (run-pg-gate.js prints it too);
#   - verify.js records `teardown (docker compose down)` as a FAILED stage, so
#     the summary is RED even when all test stages passed;
#   - error messages carry the command and exit status, never secrets.
