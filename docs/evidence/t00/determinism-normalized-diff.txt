# T00 determinism comparison (M-5)
#
# Definition — two runs of the same gate are DETERMINISTIC when:
#   1. the exit code is identical;
#   2. the 'Test Suites:' counter line is identical;
#   3. the 'Tests:' counter line is identical;
#   4. the set of suite outcomes (PASS/FAIL + suite path) is identical,
#      independent of print order;
#   5. for verify:tow, every stage result and the final verdict are identical.
#
# Explicitly outside the definition (non-deterministic observables):
#   - morgan access-log timestamps and response byte sizes (payload fields
#     such as generated ids/timestamps vary between runs);
#   - jest per-test/per-suite durations and the 'Time:' lines;
#   - the order in which jest prints PASS lines (completion order).
#
# The raw run logs are kept byte-for-byte; this artifact only diffs the
# extracted fingerprint. Reproduce with:
#   bash scripts/tow/determinism-evidence.sh
